Database backup & recovery

Use the SQLite online backup command from the project folder. It checks database integrity and writes a SHA-256 verification manifest.

.venv\Scripts\python.exe -m scripts.backup_db backup

To restore, stop the ERP server, move the original database to a safe location, then explicitly specify the verified backup and a new destination.

The utility does not schedule backups, encrypt them, copy them offsite, or perform a disaster-recovery drill. Do not process actual business records here.
